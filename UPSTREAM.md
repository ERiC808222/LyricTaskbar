# Project origin

- Upstream: [ysheng920/LyricBar](https://github.com/ysheng920/LyricBar)
- Base commit: `8d21e853ff2ada701e25a3a362904a5f4ea5be3a`
- License: MIT; the original notice is retained verbatim in `LICENSE`.
- This repository is an independently maintained derivative, not an official upstream release.

Changes include multilingual original/Chinese lyric pairs, local bilingual import, catalog identity checks and additional lyric sources; a monotonic playback clock, timing controls, four lyric transition modes and coordinated track transitions; rounded album artwork, optional login startup and fullscreen behavior; PerMonitorV2 placement recovery and original executable/tray icon assets.

The upstream media-session, taskbar, themes and interaction structure is reused and modified. The README and launcher scripts describe this derivative's executable and build path. Online lyrics, cache databases and Windows fonts are not bundled. The repository is imported from the validated 1.5.1 source snapshot rather than copying private workspace history.
