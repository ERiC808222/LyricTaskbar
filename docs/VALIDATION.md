# 验证范围

1.5.1 原始功能版本于 2026-10-14 使用 .NET SDK 9.0.318 构建，构建无警告/错误：

- 120 项行为检查：歌词解析、原文/译文配对、录音版本匹配、多语文字处理、播放时钟、设置、自启策略、全屏与显示器位置计算。
- 发布版真实 WPF 窗口恢复 15 项；全屏隐藏/恢复 8 项；多语言与动效 17 项。
- Windows Shell 提取程序的 32/16 像素图标，托盘加载同一嵌入资源。

位置计算覆盖 100%、125%、150%、200%；实际窗口验证是在 125% 缩放完成，测试窗口置于屏幕外，显示器与全屏检测通过注入模拟。未接管用户桌面，未做独占全屏游戏验证，也没有连续音乐播放的完整试听。

原始机器的目录、屏幕拓扑和用户配置不包含在本报告。公开构建的复核结果见 `public-release-validation.json`。

在线歌词样本记录来自 1.5.0 的检查，未在 1.5.1 窗口修复和本次 GitHub 上传时重新检索；它们不代表全曲库覆盖。详细条目见 [validation-1.5.1.json](validation-1.5.1.json)。
